# Pedra, Papel e Tesoura

## Objetivo do jogo

O objetivo é disputar partidas de Pedra, Papel e Tesoura contra o computador. O jogador deve escolher uma das três opções e tentar vencer duas partidas antes do computador.

## Regras do jogo

- O jogador escolhe entre Pedra, Papel e Tesoura.
- O computador realiza uma escolha aleatória.
- Pedra vence Tesoura.
- Tesoura vence Papel.
- Papel vence Pedra.
- Quando as duas escolhas são iguais, ocorre um empate.
- Empates não adicionam pontos a nenhum jogador.
- O jogo é disputado no formato melhor de 3.
- O primeiro a alcançar 2 vitórias vence o jogo.
- Após o fim do jogo, é necessário clicar em "Reiniciar Jogo" para iniciar uma nova partida.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- jQuery

## Instalação

Não é necessário realizar uma instalação. Para executar o jogo localmente, basta baixar ou clonar o repositório e abrir o arquivo `index.html` em um navegador.
